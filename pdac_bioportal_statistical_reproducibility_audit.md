#### 2. Manuscript Methods Draft (Peer-Reviewed Format)

##### **Differential Expression Analysis of TCGA-PAAD and GTEx Cohorts**
Differential expression analysis between TCGA-PAAD primary tumors ($n=178$) and GTEx normal pancreas tissue ($n=167$) was conducted using both non-parametric hypothesis testing on harmonized transcript-per-million (TPM) values and empirical Bayes moderated linear modeling on expected counts.

###### **Non-Parametric Rank-Sum Analysis (Primary Pipeline)**
Gene-level expression values from the UCSC Xena Toil recompute pipeline—quantified via RSEM (v1.2.22) using GENCODE v23 annotations and $\log_2(\text{TPM} + 0.001)$ transformed—were evaluated using a two-sided Wilcoxon rank-sum test (Mann-Whitney U test; `scipy.stats.mannwhitneyu`, method="auto"). For each gene, the test statistic $U$ was computed as:

$$U_1 = \sum_{i \in \text{Tumor}} R_i - \frac{n_1(n_1 + 1)}{2}$$

where $R_i$ denotes the rank of sample $i$ in the combined sample distribution ($N = n_1 + n_2 = 345$), and $n_1 = 178$ (tumor), $n_2 = 167$ (normal). P-values underflowed to zero by floating-point limitations were floor-protected at $P = 5 \times 10^{-300}$.

Effect size was calculated using both the difference in group log-means ($\text{mean}(\log_2\text{TPM}_{\text{Tumor}}) - \text{mean}(\log_2\text{TPM}_{\text{GTEx}})$) and the non-parametric rank-biserial correlation ($r$):

$$r = 1 - \frac{2 U_1}{n_1 n_2}$$

where $r \in [-1, +1]$. Multiple testing correction was performed using the Benjamini-Hochberg procedure (`statsmodels.stats.multitest.multipletests`, method="fdr_bh") to generate False Discovery Rate (FDR) $q$-values. Primary significance was defined as FDR $q < 0.05$ and $|\log_2\text{FC}| \ge 1.0$.

###### **Parametric limma-voom Analysis (Secondary Pipeline)**
To validate non-parametric findings against count-based empirical Bayes models, RSEM expected count matrices ($\log_2(\text{expected\_count} + 1)$) were back-transformed to raw expected counts ($y = 2^x - 1$). Unexpressed or lowly expressed genes were filtered out using `edgeR::filterByExpr(group = group)`, retaining genes with sufficient counts across samples. Trimmed Mean of M-values (TMM) normalization factors were calculated (`edgeR::calcNormFactors`, method="TMM"). Precision weights were estimated using the `voom` transformation (`limma::voom`). Linear models were fitted using `limma::lmFit`, followed by empirical Bayes moderation (`limma::eBayes`). Moderated $t$-statistics, $B$-statistics (log-odds of differential expression), and Benjamini-Hochberg adjusted $P$-values (`voom_qval`) were computed.

###### **Cross-Method Robust DEGs**
Genes meeting both non-parametric criteria ($\text{FDR}_W < 0.05$, $|\log_2\text{FC}_W| \ge 1.0$) and parametric limma-voom criteria ($\text{FDR}_V < 0.05$, $|\log_2\text{FC}_V| \ge 1.0$) with concordant log-fold change sign ($\text{sign}(\log_2\text{FC}_W) = \text{sign}(\log_2\text{FC}_V)$) were defined as *Cross-Method Robust Differentially Expressed Genes* ($n = 5,522$).

##### **Bivariate Co-Expression & Linear Regression**
Bivariate gene-gene co-expression was assessed using both parametric Pearson correlation coefficient ($r$) and non-parametric Spearman rank correlation coefficient ($\rho$).

###### **Pearson Correlation Coefficient ($r$)**
$$r_{X,Y} = \frac{\sum_{i=1}^{n} (x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum_{i=1}^{n} (x_i - \bar{x})^2 \sum_{i=1}^{n} (y_i - \bar{y})^2}}$$

###### **Spearman Rank Correlation Coefficient ($\rho$)**
Calculated by transforming expression vectors $X$ and $Y$ to fractional rank vectors $R_X$ and $R_Y$ (handling ties via average ranking):

$$\rho = \frac{\sum_{i=1}^{n} (R_{x,i} - \bar{R}_x)(R_{y,i} - \bar{R}_y)}{\sqrt{\sum_{i=1}^{n} (R_{x,i} - \bar{R}_x)^2 \sum_{i=1}^{n} (R_{y,i} - \bar{R}_y)^2}}$$

Ordinary Least Squares (OLS) linear regression was fitted ($y = mx + b$) to project trend lines:

$$m = \frac{\sum (x_i - \bar{x})(y_i - \bar{y})}{\sum (x_i - \bar{x})^2}, \quad b = \bar{y} - m \bar{x}$$

To prevent cohort-driven confounding correlations caused by pooling distinct tissue distributions, the TCGA-GTEx module isolates correlation calculations into cohort-specific modes:
1. **TCGA Primary Tumor ($n=178$)** — Default mode
2. **GTEx Normal Pancreas ($n=167$)**
3. **Pooled Exploratory ($n=345$)** (with cohort confounding warning tag)

Secondary TCGA solid tissue normal samples ($n=4$) are strictly excluded from correlation calculations.

##### **Differential Expression in SBRT Neoadjuvant Cohort (GSE225767)**
Differential expression for bulk RNA-seq samples ($n=55$) was conducted using DESeq2 (median-of-ratios normalization, negative binomial Wald test). Because Pre-SBRT biopsies ($n=26$) and Post-SBRT resections ($n=29$) were derived from completely independent patient populations (unpaired), two-sample unpaired statistical models were evaluated. Statistical significance was designated at raw $p < 0.05$ and $|\log_2\text{FC}| > 1.5$. Response-based comparisons (Responders $n=11$ Pre / $n=15$ Post vs Non-Responders $n=4$ Pre / $n=5$ Post) were classified as exploratory hypothesis-generating analyses due to small non-responder group sizes.

##### **Heatmap Normalization & Clustering**
Heatmap matrix rendering (`Heatmap.tsx`) calculates sample Z-score normalization per gene row across displayed sample columns:

$$Z_{i,j} = \frac{x_{i,j} - \mu_i}{\sigma_i}$$

where $\mu_i$ is the gene mean expression and $\sigma_i$ is the sample standard deviation. Z-scores are clamped to a visual color saturation window of $[-3.0, +3.0]$.

##### **Chunked Sparse Binary Architecture**
Instead of forcing the user's browser to download massive multi-gigabyte matrices or making tens of thousands of microscopic HTTP requests, gene vectors are grouped into 200-gene binary chunks (`expression_chunks/chunk_xxx.bin`). This optimizes HTTP request batching while keeping individual file sizes below 1 MB.

##### **Zero-Copy Float32 Array Slicing**
The 27.71 MB TCGA-GTEx matrix (`tcga_gtex_expression_matrix.bin`) is fetched once into an `ArrayBuffer`. When a user selects a gene, JavaScript reads the 349 Float32 sample values ($349 \times 4 = 1,396$ bytes) using direct array offsets (`new Float32Array(buffer, rowOffset, 349)`), performing $O(1)$ zero-copy memory access.

##### **Float16 Quantization & IEEE 754 Decoding**
Single-nucleus and spatial expression vectors are stored using IEEE 754 half-precision (Float16) sparse formats. A custom client-side bit-shifting function (`f16ToF32()`) expands Float16 values into Float32 arrays in real-time during canvas rendering, cutting binary storage footprint by $50\%$.

##### **Multi-Tiered Caching**
1. **HTTP/CDN Browser Cache:** Static chunk files and binary matrices are cached by GitHub Pages CDN (`Cache-Control: max-age=600`).
2. **Chunk Buffer Cache (`chunkCacheRef`):** Component-level React `useRef` maps downloaded chunk IDs to `ArrayBuffer` instances (`Map<number, ArrayBuffer>`), preventing duplicate network fetches when exploring multiple genes within the same chunk.
3. **LRU Vector Cache (`exprCache`):** Single-nucleus explorer maintains a Least Recently Used (LRU) Map cache (maximum 60 decoded gene vectors), keeping vector lookups instant during rapid autocomplete searches.
